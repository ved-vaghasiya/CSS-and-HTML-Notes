• What is HTML?
→ Stands for HyperText Markup Language.
→ Gives structure to a webpage (વેબસાઇટ નું કંકાલ / હાડપિંજર - Skeleton of a website).
🏠 Real-life: HTML is like the bricks and walls of a house, CSS is paint and interior.
<p>My first web page</p> :- My first web page (shown on screen)
Remember: HTML is not a programming language; it has no logic or loops, only tags!
Mistake: Thinking HTML alone can make a beautiful website. It only makes the raw skeleton!
• Basic HTML Document Structure
→ Every HTML file must follow this exact hierarchy:
<!DOCTYPE html> → Tells browser it's HTML5
<html> → Root element of page
  ├── <head> → Metadata, title, fonts (invisible to user)
  └── <body> → Visible content (headings, paragraphs, images)
</html>
→ <head> = મગજ (brain - settings), <body> = શરીર (visible body)
<title>My Site</title> :- Shows on browser tab at top
Remember: Only things inside <body> are shown on the screen!
Mistake: Putting <h1> or <p> inside <head>. Head is ONLY for metadata and title!
